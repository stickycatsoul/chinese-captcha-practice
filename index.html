验证Chinese CAPTCHA Practice

Thirteen interaction styles you meet on Chinese sites, drilled one at a time. Only some are genuinely China-specific — the ones built on reading Chinese characters or idioms. Others are global mechanics that Chinese vendors adopted. Each module says which it is, names the vendors shipping it, and cites an open-access paper.

Built by Eve C. with Claude (Anthropic). Free to use, adapt and share for your learning. The CAPTCHA reproductions here are original approximations built from published descriptions — no vendor assets or captured challenge images are embedded.

If you spot an inaccuracy — a vendor attribution, a mismatched citation, anything — please open an issue describing what's wrong, or submit a PR if you already have the fix. Both are welcome.

Real labelled samples

This tool renders clean approximations. To see what live challenges actually look like — photographic backgrounds, distorted glyphs, the prompt strip along the bottom edge — work from real captures:

Amort/captcha_chinese_click_1 on Hugging Face — 451 annotated Chinese click-sequence CAPTCHAs, Apache-2.0, ~25 MB. Each image is 344 px wide with bounding boxes and category labels separating the prompt-strip characters from the ones scattered over the background.

Browse it in the Data Studio viewer without downloading anything, or pull it with the datasets library for detection work.
